# Arrow-Faz — Application mobile

Application gratuite de conseils informatiques et de montage PC.

## Téléchargement

- **Android** : voir la [dernière release](https://github.com/SamArrow-ai/arrow-faz-app/releases/latest) et télécharger le fichier `.apk`

## Contenu de ce dépôt

Ce dépôt public sert uniquement à :
- Distribuer l'APK Android via les **Releases**
- Héberger `prix-live.json`, mis à jour automatiquement chaque nuit par le scraper GitHub Actions

Le code source de l'application n'est pas publié.

## Prix des composants

Les prix sont mis à jour quotidiennement par un workflow `.github/workflows/update-prices.yml`.

URL du fichier JSON : `https://raw.githubusercontent.com/SamArrow-ai/arrow-faz-app/main/prix-live.json`
